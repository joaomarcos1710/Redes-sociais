# EXEMPLOS PRÁTICOS | JOÃO MARCOS - CAPAS SOCIAIS

## Como usar os templates

Cada template SVG pode ser:
1. **Editado em Figma**: Importar o SVG, ele virá com textos editáveis
2. **Personalizado em Canva**: Adicionar como background ou elemento
3. **Integrado em seu workflow**: Usar CSS/variables para adaptar cores e fontes

## CHECKLIST PARA SUAS CAPAS

Antes de postar, verifique:

### Visual
- [ ] Legível em thumbnail (100px)?
- [ ] Contraste suficiente?
- [ ] Foto de qualidade profissional?
- [ ] Tipografia alinhada?
- [ ] Paleta respeitada (preto/branco/off-white + vermelho estratégico)?

### Identidade
- [ ] Parece João Marcos?
- [ ] Consistente com outras?
- [ ] Diferente o suficiente para não parecer clone?
- [ ] Categoria identificável (mas não óbvia)?

### Conteúdo
- [ ] Headline claro?
- [ ] Responde "por que ver"?
- [ ] Sem informação desnecessária?
- [ ] Desejável clicar/compartilhar?

### Técnico
- [ ] SVG estruturado?
- [ ] Compatível com Figma?
- [ ] Dimensões corretas (1080×1350 ou 1080×1920)?
- [ ] Textos como texto (não paths)?

## PRÓXIMAS CRIAÇÕES

Quando criar capas novas:

1. **Escolha o pilar** (teologia, corrida, etc)
2. **Escolha o template** que melhor se adequa
3. **Use os tokens** de cor e tipografia
4. **Siga as regras** de espaço negativo e hierarquia
5. **Verifique a grid** (como fica com outras capas?)
6. **Auditoria final** (checklist acima)
