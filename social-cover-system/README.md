## 🎯 O QUE É ESTE SISTEMA?

Um conjunto de **10 templates base em SVG** + **guias editoriais completas** que permitem criar capas para Instagram e TikTok que:

✓ São reconhecíveis como suas em qualquer contexto
✓ Funcionam individualmente com impacto
✓ Funcionam coletivamente com ritmo visual

✓ Podem ser escaladas para 1 ano de conteúdo sem parecerem clones

## 📐 10 TEMPLATES BASE

### 01. **EDITORIAL** 
Proporção: 60% foto + 40% tipo sobre overlay
- Headline grande sobre fotografia com overlay
- Melhor para: Conteúdo direto com foto impactante
- Formatos: Feed, Reels, Stories

### 02. **FOTOGRÁFICO**
Proporção: 80% foto + 20% tipo discreta
- Foto como protagonista absoluto
- Melhor para: Fotos muito fortes
- Formatos: Feed, Reels, Stories

### 03. **TIPOGRÁFICO**
Proporção: 70% tipo + 30% vazio
- Headlines múltiplos, sem foto
- Melhor para: Conceitos, números, afirmações
- Formatos: Feed, Stories

### 04. **TEXTO SOBRE FOTO**
Proporção: Foto full + texto centralizado
- Citações, afirmações, reflexões
- Melhor para: Frases impactantes
- Formatos: Reels, Feed

### 05. **SPLIT SCREEN**
Proporção: 50% foto + 50% tipo lado a lado
- Contraste, antes/depois, comparação
- Melhor para: Transformações, contraste
- Formatos: Reels, Feed

### 06. **MINIMALISTA**
Proporção: 20% conteúdo + 80% vazio
- Elegância através da simplicidade
- Melhor para: Conceitos, reflexões profundas
- Formatos: Feed, Stories

### 07. **HEADLINE GIGANTE**
Proporção: 90% tipo grande + 10% contexto
- Uma palavra/número em tamanho extremo
- Melhor para: Impacto máximo, números
- Formatos: Reels, Stories, Feed

### 08. **LISTA**
Proporção: 60% lista + 40% espaço
- Numeração clara, itens alinhados
- Melhor para: "5 coisas...", conteúdo estruturado
- Formatos: Feed, Stories

### 09. **CITAÇÃO**
Proporção: 50% tipo + 50% foto/vazio
- Citações com atribuição
- Melhor para: Reflexões, frases memoráveis
- Formatos: Feed, Reels

### 10. **STORY/REEL CINEMATOGRÁFICO**
Proporção: Portrait completo (1080×1920)
- Foco em pessoas, cinematografico
- Melhor para: Reels, Stories
- Formatos: Reels, Stories, TikTok

## 🚀 COMO USAR

### **Opção 1: Figma** (Recomendado)
```
1. Importar template SVG
2. Editar textos (já são editáveis)
3. Substituir foto (arrastar)
4. Exportar PNG
5. Postar no Instagram
```

### **Opção 2: Canva**
```
1. Criar novo design (1080×1350 ou 1080×1920)
2. Importar SVG como background
3. Adicionar foto
4. Editar textos
5. Publicar
```

### **Opção 3: Código** (Developers)
```
Usar SVG como base para gerador dinâmico
Customizar via CSS variables
Exportar como PNG via servidor
```

## 🎯 PRINCÍPIOS DO SISTEMA

### 1. **Reconhecibilidade**
Alguém deve saber que é seu conteúdo sem ler @bomfim1710.

### 2. **Consistência com Variedade**
Cada capa segue princípios, mas não são clones.

### 3. **Hierarquia Clara**
Um elemento protagonista por capa (foto OU tipo, não ambos grandes).

### 4. **Espaço Negativo Respeitado**
Mínimo 15-20% de espaço vazio em toda composição.

### 5. **Tipografia Forte**
Headlines legíveis em thumbnail (100px).

### 6. **Fotografia Autêntica**
Pessoas reais, enquadramento profissional, sem filtros artificiais.

### 7. **Paleta Restrita**
Preto, branco, off-white + vermelho estratégico. Nada mais.

### 8. **Escalabilidade**
Sistema funciona para 365 capas sem parecer repetitivo.

## ❓ FAQ

**P: Posso modificar as cores?**
A: Sim! Edite o DESIGN-SYSTEM.md e atualize os tokens nos SVGs.

**P: Funciona no Canva?**
A: Sim! Importar SVG como background e customizar.

**P: Funciona no Figma?**
A: Sim! Importar SVG e editar diretamente.

**P: Preciso saber programação?**
A: Não! Use Figma ou Canva. Programação é apenas opção avançada.

**P: Preciso usar as fonts exatas?**
A: Não. League Gothic + Montserrat são ideais, mas alternatives funcionam.

**P: Como garantir que pareça João Marcos?**
A: Usar paleta + elementos recorrentes (linha vermelha, assinatura discreta, espaçamento).

**P: Posso combinar templates?**
A: Sim! Mas respeite o protagonismo (não misture foto grande + tipo grande).
