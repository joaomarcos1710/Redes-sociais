## PASSO 1: ESCOLHER O TEMPLATE CERTO

### Como Decidir

Responda estas perguntas:

#### A. **Tenho foto impactante?**
- ✅ Sim, muito boa → **FOTOGRÁFICO** (02) ou **EDITORIAL** (01)
- ✅ Sim, para contextualizar → **EDITORIAL** (01) ou **SPLIT** (05)
- ❌ Não tenho → **TIPOGRÁFICO** (03) ou **MINIMALISTA** (06)

#### B. **Qual é meu conteúdo?**
- Citação/Frase → **CITAÇÃO** (09) ou **TEXTO SOBRE FOTO** (04)
- Lista/Estruturado → **LISTA** (08)
- Conceito puro → **MINIMALISTA** (06) ou **TIPOGRÁFICO** (03)
- Número/Estatística → **HEADLINE GIGANTE** (07)
- Vídeo/Reel/Story → **STORY CINEMATOGRÁFICO** (10)
- Comparação → **SPLIT SCREEN** (05)

#### C. **Qual é meu pilar?**
- Teologia/Reflexão → Minimalista, Citação, Tipográfico
- Corrida/Fitness → Editorial, Fotográfico, Headline Gigante
- Conceitual/Educativo → Tipográfico, Lista, Minimalista
- Emocional → Fotográfico, Citação, Text on Photo

## PASSO 2: ABRIR EM FIGMA (RECOMENDADO)

### 2.1 Importar o Template

```
1. Abrir Figma (figma.com)
2. Criar novo arquivo
3. Menu: File > Import > Selecionar arquivo SVG do template
4. Esperar renderizar
```

**Resultado**: Template aparece como frame editável com textos selecionáveis.

### 2.2 Editar Textos

```
1. Clique duplo no texto que quer editar
2. Selecionar tudo (Cmd/Ctrl + A)
3. Digitar novo conteúdo
4. Ajustar tamanho se necessário (respeitando hierarquia)
```

### 2.3 Substitui a Foto

```
1. Clique na área de imagem (placeholder cinza)
2. Right-click > Fill > Image > Upload
3. Selecionar sua imagem
4. Ajustar enquadramento (crop)
5. Garantir que está centrada e bem enquadrada
```

### 2.4 Ajustes Finais em Figma

**Se precisar aumentar/diminuir elementos:**
```
1. Selecione o elemento
2. Redimensione pelos cantos (segure Shift para manter proporção)
3. Use Figma's layout features (Flex layout)
```

**Se precisar mudar cor:**
```
1. Selecione o elemento (texto ou forma)
2. Painel direito > Fill
3. Escolha a cor correta (usar paleta do design system)
```

## ALTERNATIVA: USAR CANVA

Se preferir não usar Figma:

### 3.1 No Canva

```
1. Canva.com > Login/Signup
2. Criar novo design (1080×1350 ou 1080×1920)
3. Menu: Uploads > Upload SVG > Selecionar template
4. Adicionar como elemento (pode usar como background)
5. Adicionar foto (arrastar ou upload)
6. Editar textos normalmente
7. Publicar/Baixar
```

**Vantagem Canva**: Mais intuitivo visualmente, nenhuma curva de aprendizado

**Desvantagem Canva**: Menos controle fino que Figma

## PASSO 4: ADICIONAR FOTOGRAFIA

### Requisitos de Foto

```
✅ Deve ser profissional
✅ Deve ter foco claro (não desfocada/genérica)
✅ Deve ter contraste adequado
✅ Deve se encaixar no formato (1080×1350 ou 1080×1920)
✅ Deve parecer real (não filtrada artificialmente)
```

### Técnicas Fotográficas

**Para Editorial/Fotográfico:**
```
- Enquadramento horizontal ou vertical
- Pessoa/ação como focal point
- Luz natural preferível
- Sem filtros exagerados
- Saturação natural
```

**Para Citações/Reflexões:**
```
- Foto pode ser mais sutil
- Pessoa contemplativa funciona bem
- Natureza, luz, espaço também funciona
- Foco em sensação, não em informação
```

**Para Splitscreen:**
```
- 2 fotos contrastantes
- Uma mais clara, uma mais escura (visualmente)
- Mesmo tamanho (540×1350 cada)
- Tema relacionado (antes/depois, lá/cá)
```

## PASSO 5: VERIFICAR CHECKLIST

Antes de exportar, responda:

### Visual (5 perguntas)
```
[ ] Legível em 100px thumbnail? 
    → Colocar em 100px, consegue ler o título?

[ ] Contraste suficiente?
    → Usar ferramenta de contraste (WebAIM)

[ ] Fotografia de qualidade?
    → Não pixelada, não blurrada, profissional

[ ] Paleta respeitada?
    → Só preto, branco, off-white + vermelho estratégico?

[ ] Sem aparência de template genérico?
    → Parece seu, não parece Canva default?
```

### Identidade (4 perguntas)
```
[ ] Parece João Marcos?
    → Alguém reconheceria como seu?

[ ] Consistente com outras capas?
    → Se você tivesse 10 dessas, pareceria coleção coesa?

[ ] Diferente o suficiente?
    → Não é clone exato de outra?

[ ] Categoria identificável?
    → Se for Corrida, vê-se que é? (mas sem exagero)
```

### Conteúdo (3 perguntas)
```
[ ] Headline claro?
    → Entende-se de primeira?

[ ] Desejável clicar?
    → Desperta curiosidade? Parece interessante?

[ ] Sem poluição?
    → Não tem excesso de elementos/informação?
```

## PASSO 6: EXPORTAR

### Em Figma

```
1. Selecionar frame (capa inteira)
2. Right-click > Export
3. Formato: PNG
4. Scale: 1x (1080×1350 ou 1080×1920)
5. Download
```

### Em Canva

```
1. Botão "Download" (canto superior direito)
2. Selecionar PNG
3. Qualidade: Máxima
4. Download automático
```

## ERROS COMUNS (E COMO EVITAR)

### ❌ Erro 1: Foto + Tipografia ambas grandes
**Solução**: Escolha um protagonista. Se foto grande, tipo pequeno. Se tipo grande, foto pequena.

### ❌ Erro 2: Texto muito pequeno
**Solução**: Testar em 100px. Se não consegue ler, aumenta.

### ❌ Erro 3: Sem espaço negativo
**Solução**: Garantir mínimo 15-20% de área vazia.

### ❌ Erro 4: Cores fora da paleta
**Solução**: Usar apenas as 4 cores principais + cinzas. Nada mais.

### ❌ Erro 5: Fonte decorativa/infantil
**Solução**: League Gothic + Montserrat apenas.

### ❌ Erro 6: Muita informação
**Solução**: Máximo 3 linhas de texto principal. Simplicidade.

### ❌ Erro 7: Foto de má qualidade
**Solução**: Usar fotos profissionais. Se duvidoso, usar versão tipográfica.

### ❌ Erro 8: Sem consistência com outras
**Solução**: Manter elementos recorrentes (assinatura, espaçamento, paleta).

## TROUBLESHOOTING

### "SVG não abre no Figma"
→ Converter para PNG e importar como image? Ou usar Canva

### "Textos não aparecem"
→ Verificar se @import do Google Fonts está carregando. Atualizar manualmente em Figma

### "Imagem fica pixelada"
→ Garantir que imagem está em alta resolução (300+ DPI). Testar com imagem de 1200×1500px+

### "Grid não fica bem"
→ Revisar estrutura de layouts escolhidos. Aplicar padrão: FOTO|TIPO|FOTO etc

### "Parece um template do Canva"
→ Adicionar mais espaço negativo. Usar apenas 2 cores máximo. Remover excesso de elementos
